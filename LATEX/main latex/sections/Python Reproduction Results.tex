\section{Python Reproduction Results}

%===============================================================================

To further verify the correctness and reproducibility of the MATLAB simulations,
all simulation cases were independently reimplemented in Python.
The following figures present the corresponding Python-based simulation results.

It should be noted that when $S=1$ (computed torque control without compensation)
or $S=2$ (computed torque control with exact feedforward disturbance compensation),
the controller does not involve the RBF neural network module.
Therefore, the parameters $S_1$ and $m$ have no effect on these two control modes.

However, the plotting scripts were implemented using a unified parameter naming
format. As a result, some figures corresponding to $S=1$ and $S=2$ cases may still
contain $S_1$ and $m$ labels in their filenames or captions.
These parameters should be ignored for $S=1$ and $S=2$ cases and are only
meaningful for the RBF-based compensation case ($S=3$).
